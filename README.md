# Locale Format Reference

เว็บอ้างอิงรูปแบบวันที่ เวลา ตัวเลข สกุลเงิน หน่วยวัด เครื่องหมายวรรคตอน การเขียน ข้อความ UI คีย์บอร์ด ที่อยู่ และเบอร์โทร สำหรับงาน Localization QA

ภาษาที่มี: German (de-DE), French (fr-FR / fr-CA), Japanese (ja-JP), Korean (ko-KR), Chinese Simplified (zh-CN), Chinese Traditional (zh-TW)

## แหล่งข้อมูล

ข้อมูลทั้งหมดสรุปจาก **Adobe Localization Style Guide** (PDF) เท่านั้น ไม่ได้ใช้ CLDR หรือแหล่งอื่น ทุกค่าในหน้าเว็บมีเลขหน้าของ PDF กำกับ

| ภาษา | ไฟล์ | เวอร์ชัน | วันที่ |
| --- | --- | --- | --- |
| de-DE | `Adobe_Style_Guide_de-DE_v.2.3.pdf` | 2.3 | July 2023 |
| fr-FR / fr-CA | `Adobe_Style_Guide_fr-FR_fr-CA_v.1.8.pdf` | 1.8 | October 2022 |
| ja-JP | `Adobe_Style_Guide_ja-JP_v.1.9_EN.pdf` (ฉบับภาษาอังกฤษ ใหม่กว่าฉบับภาษาญี่ปุ่น v1.8) | 1.9 | July 2023 |
| ko-KR | `Adobe_Style_Guide_ko-KR_v.1.7.pdf` | 1.7 | October 2022 |
| zh-CN | `Adobe_Style_Guide_zh-CN_v.1.7.pdf` | 1.7 | October 2022 |
| zh-TW | `Adobe_Style_Guide_zh-TW_v.1.9.pdf` | 1.9 | October 2022 |

ตัว PDF ไม่ได้อยู่ใน repo นี้

- ตัวอย่าง (ปุ่มที่คลิกคัดลอกได้) คัดลอกตามที่ guide เขียน `…` คือส่วนที่ละไว้ และ `→` คือการแทนที่ตามตารางใน guide
- ตัวอย่างสีแดงขีดฆ่าคือรูปแบบที่ guide ระบุว่าผิด
- กฎเป็นการสรุปความเป็นภาษาไทยและอังกฤษ
- `—` คือ guide เล่มนั้นไม่ได้พูดถึงหัวข้อนี้
- ⚠ คือ guide เขียนขัดกันเอง ควรถาม IPM ก่อนรายงานเป็นบั๊ก
- PDF ไม่ได้เก็บ NBSP เป็นตัวอักษรจริง หน้าเว็บจึงใส่ NBSP (U+00A0) ตามที่กฎของแต่ละภาษากำหนด

หัวข้อจากเวอร์ชันก่อนที่ไม่มีใน PDF ถูกเอาออก: ค่าที่สร้างจาก CLDR (ชื่อเขตเวลา เวลาแบบสัมพัทธ์ วันแรกของสัปดาห์ การนับสัปดาห์ สัญกรณ์วิทยาศาสตร์ ชื่อภาษา) ตารางการเรียงลำดับแบบ collation แผงอักขระพิเศษ DE/FR และหน้าชุดทดสอบอักขระ

## วิธีใช้

เปิด `index.html` ใน browser ได้เลย ไฟล์นี้มีทุกอย่างอยู่ในตัว (ฟอนต์โหลดจาก Google Fonts)

- **ตารางเทียบทุกภาษา** และ **ดูทีละภาษา** สลับได้จากแท็บด้านบน (ลิงก์ตรงได้ด้วย `#compare`, `#de`, `#fr`, `#ja`, `#ko`, `#zh-hans`, `#zh-hant`)
- หน้าของแต่ละภาษามีเช็คลิสต์จุดที่ต้องตรวจ พร้อมเลขหน้าอ้างอิง
- คลิกตัวอย่างเพื่อคัดลอกพร้อมอักขระจริง รวมถึง NBSP
- สวิตช์ "แสดง NBSP" ใช้ไฮไลต์ช่องว่างไม่ตัดบรรทัด
- วางเมาส์บนป้าย `p.38` เพื่อดูชื่อไฟล์ PDF
- กด `/` เพื่อค้นหา
- ปุ่ม **ไทย / EN** มุมขวาบนใช้สลับภาษาของหน้าเว็บ (จำค่าไว้ใน browser)

ถ้าจะเผยแพร่เป็นเว็บ ให้เปิด GitHub Pages (Settings › Pages › Deploy from branch › `main` / root)

## โครงสร้าง

```
index.html          เว็บที่ build แล้ว (เปิดไฟล์นี้)
src/template.html   HTML / CSS / JS ของหน้าเว็บ
src/content.js      ข้อมูลทั้งหมด: แหล่งที่มา หมวดหมู่ รายการ เช็คลิสต์ (ไทย/อังกฤษอยู่ในไฟล์นี้)
scripts/check.js    ตรวจว่าทุกช่องมีเลขหน้าที่อยู่ในช่วงของ PDF และข้อความมีทั้งไทยและอังกฤษ
scripts/build.js    รวมทุกอย่างเป็น index.html
```

## แก้ไขและ build ใหม่

แต่ละช่องใน `src/content.js` มีรูปแบบ:

```js
{ s: "ตัวอย่าง" หรือ ["ตัวอย่าง", ...],   // คัดลอกตาม PDF
  x: ["รูปแบบที่ผิด"],                     // ถ้า guide ระบุไว้
  r: t("กฎ (ไทย)", "rule (English)"),
  w: t("guide ขัดกันเอง (ไทย)", "contradiction (English)"),
  na: t("ไม่ใช้กับภาษานี้", "Doesn't apply"),
  p: 38 หรือ "36–37" หรือ "24, 33" }      // เลขหน้าใน PDF
```

ใช้ `null` ถ้า guide เล่มนั้นไม่ได้พูดถึงหัวข้อนี้

ต้องใช้ Node.js

```sh
node scripts/check.js   # ตรวจข้อมูล
node scripts/build.js   # build index.html
```
